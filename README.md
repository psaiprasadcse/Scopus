# Scopus Research Insights — Multi-Year Comparison (GitHub Pages)

A **code-only** static dashboard for comparing Scopus publication reports across two, three, or more years at **institutional level** and for **individual Scopus authors**.

## File list: upload to GitHub repository root

- `index.html` — dashboard layout, range selection, comparison tab.
- `app.js` — browser-only workbook loader, filters, charts, tables, CSV exports.
- `dashboard-core.js` — year-wise deduplication, author-year aggregation and CiteScore quartiles.
- `styles.css` — responsive interface and comparison graphs.
- `.nojekyll` — tells GitHub Pages to serve files without Jekyll processing.
- `README.md` — instructions.

**Do NOT upload** the Python `fetch.py`, Scopus API keys, author input spreadsheets, or publication Excel reports to a public repository. There is intentionally **no `data/` folder** and no automatic workbook download from GitHub.

## How to publish

1. Go to https://github.com/new and create a repository, e.g. `scopus-research-dashboard`.
2. Upload the six website files above to the **root** of the repository (not the enclosing ZIP).
3. Commit them to the `main` branch. If replacing an earlier site, overwrite its `index.html`, `app.js`, `dashboard-core.js`, and `styles.css` and commit changes.
4. Open **Settings → Pages → Build and deployment → Deploy from a branch**; choose branch **main** and folder **/(root)**.
5. Open `https://YOUR-USERNAME.github.io/scopus-research-dashboard/`. Deployment can take some time to appear.
6. Click **Upload Excel**, selecting the report output generated by the *separate local Mac program* `fetch.py` (not the two-column author-input workbook).

The website uses the SheetJS JavaScript library from `https://cdn.sheetjs.com/` to read Excel files **in the browser's memory**. It does not POST workbooks to a server or save them to your GitHub repository. Internet access is required to load the Excel-reading library. Data is discarded when the tab is refreshed or **Clear data** is clicked.

## Expected report formats

**Preferred:** One combined `Scopus_Report_2024_to_2026.xlsx` generated by the updated local Python `fetch.py`. It includes:

- Monthly Summary — one author per year and an explicit `Publication Year` column.
- Scopus Records — one row per author/paper, including `Scopus Search Year`, date, source, DOI, CiteScore, quartile and Scopus EID.
- Unique Papers; Journal Metrics; Quartile Summary.
- Yearly Comparison and Author-Year Summary.
- Google Scholar Check (optional); Errors; Run Info.

**Also compatible:** The older single-year `Scopus_Monthly_Report_2026.xlsx` files. Choose several reports together in the file picker to combine them in the same browser session. Overlapping author-year/paper rows are deduplicated by author ID, publication year and paper key.

## Compare years

1. Upload the combined Excel report (or multiple annual reports).
2. Use **From year** / **To year** or **Last 2 years**, **Last 3 years**, **All years**.
3. The **Overview** tab shows totals for the selected period. Institution totals deduplicate faculty co-authorship; an individual author's own papers are counted separately.
4. Open **Year comparison** to see the year-on-year total bar chart, stacked Q1–Q4 distribution, growth percentages, summary table and searchable author-by-year table.
5. Search/select an author from the left sidebar. The comparison charts switch to that author. Click **All authors** to return to institution-wide statistics.
6. Export yearly or author-wise CSV files if needed. **Publications**, **Author ranking**, and **Journal metrics** respond to the same selected range.

Demo mode contains **fictional 2024–2026 data** and can be used for immediate testing.

## Important methodological definitions

- **Publication year and month:** Scopus Search publication year and publication cover date. **Not** the month/year first indexed by Scopus.
- **Institutional papers:** A co-authored paper is counted **once per publication year** at the institution level. It may count once for each coauthor in the author ranking.
- **Q1–Q4:** Based on the journal's **highest available completed CiteScore ASJC percentile**; not SJR/JCR quartiles and not an indicator of a paper's intrinsic quality.
- **Historical comparison limitation:** The Python script currently applies the **latest completed CiteScore snapshot returned when the report is created** to all publication years. Therefore, the 2024 quartile chart represents the quartiles of journals publishing 2024 papers according to that snapshot, *not necessarily their actual 2024 historical quartiles*. The workbook includes `CiteScore Year` to make this explicit.
- **Missing metrics:** Unavailable CiteScore percentile remains **N/A**, not Q4.
- **Incomplete API queries:** Failed author-year requests are marked `ERROR` in `Monthly Summary` and the `Errors` worksheet. The dashboard warns about incomplete years and uses `⚠ Failed` instead of a verified zero for the affected author/year in the comparison table.
- **Scopus paper links:** Generated from each paper's Scopus document ID as `https://www.scopus.com/inward/record.uri?partnerID=HzOxMe3b&scp=DOCUMENT_ID&origin=inward`; login may still be required.
- **Source attribution:** Respect Elsevier's Scopus data/API and journal-metrics license and redistribution terms before publishing data.
